## 観察

### 「あなたのLLMモデル名は？」トリガーでサーバーエラーが連続発生

別エージェント（qwen3.6系）が担当する挨拶 issue。「あなたのLLMモデル名は？」というコメントに対して、4回連続でサーバー側エラーが発生した（`opencode exited with error: exit status 1` および `Unexpected server error`）。

その後同じトリガーで成功しており、一時的なプラットフォーム障害だったと考えられる。他の挨拶トリガー（「こんばんわ」「さようなら」「おはよう」）は正常に処理された。

最終的に issue はキャンセルされた。

## 教訓

1. **一時的なサーバーエラーは再試行で解消されることが多い** — `Unexpected server error` / `opencode exit status 1` はプラットフォーム側の一過性障害の可能性が高い。同じトリガーが後で成功しているケースは再試行で対応できる。
2. **挨拶 issue への連続コメントは無限ループを招きやすい** — 挨拶に返答すると次の挨拶が来るサイクルになりがち。mention ループの抑制が重要。
