# プロジェクト概要

## 目的

`react-spreadsheet` は、JSONファイルに格納された複数のテーブルデータをブラウザ上でスプレッドシート形式で閲覧・編集するための社内/個人用データ管理Webアプリケーションである。

Google スプレッドシートのような汎用ツールではなく、特定のJSONスキーマ（複数のテーブルを持つデータセット）を操作するために特化した設計になっている。

## 主な機能

| 機能 | 詳細 |
|------|------|
| 複数テーブル管理 | 1つのJSONファイルに複数テーブルを格納し、左サイドバーで切り替え可能 |
| セル編集 | クリック・ダブルクリック・キーボード操作によるインライン編集 |
| テキストフィルタリング | テーブル内の任意の列に対してリアルタイム絞り込み |
| 行の追加・削除 | 選択行の複製追加、選択行の一括削除 |
| 列幅リサイズ | ヘッダーのドラッグ操作で列幅を動的変更 |
| バリデーション | 列の型（int/number/string/boolean）に応じた入力値検証 |
| エラー表示 | バリデーションエラーをセルのツールチップで表示 |
| ファイル保存・読み込み | ExpressサーバーのAPIを通じてJSONファイルの読み書き |
| 仮想スクロール | 大量データでも高速にスクロールできる仮想化レンダリング |
| 変更ハイライト | 編集済みセルを黄色、エラーセルを赤色でハイライト |

## アプリケーション構成

```
ブラウザ (React SPA)
    ↕ REST API (/api/files/:name)
Expressサーバー (server.mjs)
    ↕ ファイルI/O
var/ ディレクトリ (JSONファイル群)
```

- フロントエンドは Create React App (CRA) で構築されたSPA
- バックエンドは極めてシンプルなExpressサーバー（読み書きのみ）
- データはすべて `var/` ディレクトリ以下のJSONファイルとして永続化
