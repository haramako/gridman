# UI・ページ構成

## ページ構成

```
/                         プロジェクト選択
/project/:id              プロジェクトホーム（テーブル一覧）
/project/:id/table/:name  テーブル/ビュー表示（メイン画面）
/project/:id/search       横断検索結果
/project/:id/schema/:name スキーマ編集（設定画面）
```

## スプレッドシートビュー（表形式）

現在の実装を発展させた形。

```
│ ツールバー: [🔍 スライム  x] [+ 行追加] [- 行削除] [表形式▼] [列設定] │
├──┬──────────────┬──────┬────────┬──────────┬────────────────────────┤
│  │ name         │ hp   │ attack │ element  │ drops                  │
├──┼──────────────┼──────┼────────┼──────────┼────────────────────────┤
│1 │ スライム      │  10  │   3    │ water    │ [回復ポーション]       │
│2 │ ゴブリン      │  25  │   8    │ -        │                        │
│3 │▶ドラゴン      │ !500 │  80    │ fire     │ [竜の牙][竜の鱗]      │
│4 │ オーク        │  40  │  15    │ -        │ [鉄の剣]              │
└──┴──────────────┴──────┴────────┴──────────┴────────────────────────┘
```

**セル状態の視覚的表現:**

| 状態 | 表示 |
|------|------|
| 通常 | 白背景 |
| 編集済み（未保存） | 黄色背景 |
| バリデーション違反 | 赤枠 + ツールチップ |
| 参照型 | 参照先のname表示（IDは非表示）|
| JSON型 | `[要素数]` または省略表示 |
| 選択中 | 青いハイライト枠 |
| 編集中 | インライン入力フィールド |

**カラムヘッダー:**

```
│ name 🔤  │ hp 🔢  │ element 📋  │ drops 📦   │
```
型アイコンでカラムの型を表示。クリックでソート。

## キーボードショートカット

| ショートカット | 動作 |
|-------------|------|
| 矢印キー | カーソル移動 |
| Enter / F2 | 編集開始 |
| Escape | 編集キャンセル / パネルを閉じる |
| Tab | 次のセルへ（編集確定） |
| Delete / Backspace | セル値クリア |
| Ctrl+S | 保存 |
| Ctrl+Z | 元に戻す（undo） |
| Ctrl+F | テーブル内フィルター |
| Ctrl+Shift+F | 横断検索 |
| Ctrl+Enter | 行追加（編集中） |

---

## レスポンシブ対応方針

- **メインターゲット:** デスクトップ（1280px以上）
- **タブレット（768px〜）:** 左サイドバーを折りたたみに変更
- **モバイル:** 対応しない（ゲームデータ編集ツールの性質上不要）
