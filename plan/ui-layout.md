## スプレッドシートビュー

```
│ ツールバー: [フィルター入力] [+ 行追加] [- 行削除] [列設定] │
├──┬──────────────┬──────┬────────┬──────────┬────────────────┤
│  │ name 🔤      │ hp 🔢│ attack │ element  │ drops          │
├──┼──────────────┼──────┼────────┼──────────┼────────────────┤
│1 │ スライム      │  10  │   3    │ water    │ [回復ポーション]│
│2 │ ゴブリン      │  25  │   8    │ -        │                │
│3 │ ドラゴン      │ 500  │  80    │ fire     │ [竜の牙][竜の鱗]│
└──┴──────────────┴──────┴────────┴──────────┴────────────────┘
```

### セル状態の視覚表現

| 状態 | 表示 |
|------|------|
| 通常 | 白背景 |
| 編集済み（未保存） | 黄色背景 |
| バリデーション違反 | 赤枠 + ツールチップ |
| 参照型 | 参照先の name 表示（ID は非表示）|
| json 型 | `[要素数]` などの省略表示 |
| 選択中 | 青いハイライト枠 |
| 編集中 | インライン入力フィールド |

カラムヘッダーに型アイコンを表示（例: `name 🔤`, `hp 🔢`）。

## ページ/カードビュー（Phase 3）

レコードを1件ずつ閲覧・編集するビュー。レイアウトは JSON テンプレートで定義する。

### レイアウト定義 (*.page.json)

```json
{
  "name": "敵詳細カード",
  "table": "enemy",
  "layout": [
    { "type": "field", "key": "name",    "label": "名前",   "widget": "text" },
    { "type": "field", "key": "hp",      "label": "HP",     "widget": "number" },
    { "type": "field", "key": "element", "label": "属性",   "widget": "select" },
    {
      "type": "section",
      "label": "ドロップアイテム",
      "children": [
        { "type": "field", "key": "drops", "widget": "table",
          "columns": ["itemId", "rate"] }
      ]
    },
    { "type": "field", "key": "skills", "label": "スキル", "widget": "tag-list" }
  ]
}
```

**widget 種類:**

| widget | 説明 |
|--------|------|
| `text` | テキスト入力 |
| `number` | 数値入力 |
| `select` | enum 用セレクトボックス |
| `checkbox` | boolean 用 |
| `table` | json[] 型をミニテーブルで表示 |
| `tag-list` | ref[] 型をタグ形式で表示 |
| `json` | JSON テキストエディター（fallback）|

GUI でのレイアウト編集は Phase 3以降。

## スキーマ編集画面（Phase 4）

```
┌───────────────────────────────────────────────────────────────┐
│ [←] enemy テーブル / スキーマ編集                            │
├────┬──────────┬───────────┬────────────┬──────────┬──────────┤
│ 順 │ キー     │ 表示名    │ 型         │ 必須     │ バリデ   │
├────┼──────────┼───────────┼────────────┼──────────┼──────────┤
│ ⠿  │ name     │ 名前      │ string ▼   │ ✓        │ [編集]   │
│ ⠿  │ hp       │ HP        │ integer ▼  │ ✓        │ [編集]   │
│ ⠿  │ element  │ 属性      │ enum ▼     │          │ [編集]   │
├────┴──────────┴───────────┴────────────┴──────────┴──────────┤
│ [+ 列を追加]                                                  │
└───────────────────────────────────────────────────────────────┘
```

Phase 1〜3 はスキーマを JSON ファイルで直接編集する。

## キーボードショートカット

| ショートカット | 動作 |
|-------------|------|
| 矢印キー | カーソル移動 |
| Enter / F2 | 編集開始 |
| Escape | 編集キャンセル |
| Tab | 次のセルへ（編集確定）|
| Delete / Backspace | セル値クリア |
| Ctrl+S | 保存 |
| Ctrl+Z | Undo（Phase 3）|
| Ctrl+F | テーブル内フィルター |
| Ctrl+Shift+F | 横断検索（Phase 2）|
| Ctrl+Enter | 行追加（編集中）|

---

## レスポンシブ対応方針

- **メインターゲット:** デスクトップ（1280px 以上）
- **タブレット（768px〜）:** 左サイドバーを折りたたみに変更
- **モバイル:** 対応しない（ゲームデータ編集ツールの性質上不要）
