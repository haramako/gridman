### セル状態の視覚表現

| 状態 | 表示 |
|------|------|
| 通常 | 白背景 |
| 編集済み（未保存） | 黄色背景 |
| バリデーション違反 | 赤枠 + ツールチップ |
| 参照型 | 参照先の name 表示（ID は非表示）|

| 編集中 | インライン入力フィールド |

## ページ/カードビュー（Phase 3）

レコードを1件ずつ閲覧・編集するビュー。レイアウトは JSON テンプレートで定義する。

### レイアウト定義 (*.page.json)

```json
{
  "name": "敵詳細カード",
  "table": "enemy",
  "layout": [
    { "type": "field", "key": "name",    "label": "名前",   "widget": "text" },
    { "type": "field", "key": "hp",      "label": "HP",     "widget": "number" },
    { "type": "field", "key": "element", "label": "属性",   "widget": "select" },
    {
      "type": "section",
      "label": "ドロップアイテム",
      "children": [
        { "type": "field", "key": "drops", "widget": "table",
          "columns": ["itemId", "rate"] }
      ]
    },
    { "type": "field", "key": "skills", "label": "スキル", "widget": "tag-list" }
  ]
}
```

**widget 種類:**

| widget | 説明 |
|--------|------|
| `text` | テキスト入力 |
| `number` | 数値入力 |
| `select` | enum 用セレクトボックス |
| `checkbox` | boolean 用 |
| `table` | json[] 型をミニテーブルで表示 |
| `tag-list` | ref[] 型をタグ形式で表示 |
| `json` | JSON テキストエディター（fallback）|

GUI でのレイアウト編集は Phase 3以降。

## キーボードショートカット

### 非エディット状態（セレクション操作）

| ショートカット | 動作 |
|-------------|------|
| ↑ / ↓ / ← / → | カーソル移動 |
| Shift+↑ / ↓ / ← / → | 矩形選択の範囲拡張 |
| Home | 行内の最初のカラムへ移動 |
| End | 行内の最後のカラムへ移動 |
| Enter / F2 | エディット開始 |
| Tab | 右のセルへ移動 |
| Shift+Tab | 左のセルへ移動 |
| Delete / Backspace | セル値クリア（数値→0、文字列→空文字） |
| 印字可能文字 | タイプ編集（その文字を初期値としてエディット開始） |

### エディット状態（入力中）

| ショートカット | 動作 |
|-------------|------|
| Enter | 変更確定 → 下のセルへ移動 |
| Tab | 変更確定 → 右のセルへ移動 |
| Shift+Tab | 変更確定 → 左のセルへ移動 |
| Escape | 変更キャンセル → グリッドにフォーカス戻し |

### グローバル

| ショートカット | 動作 |
|-------------|------|
| Ctrl+S | 保存 |
| Ctrl+Z | Undo（Phase 3）|
| Ctrl+Y | Redo（Phase 3）|
| Ctrl+F | テーブル内フィルター |
| Ctrl+Shift+F | 横断検索（Phase 2）|

## エディット状態の遷移

セルは **非エディット状態** と **エディット状態** の2つのモードを持つ。

```
非エディット状態
  ├─ Enter / F2 → エディット状態（既存値を引き継ぎ）
  ├─ 印字可能文字 → エディット状態（入力文字を初期値に設定）
  └─ マウスダブルクリック → エディット状態（既存値を引き継ぎ）

エディット状態
  ├─ Enter / Tab / Shift+Tab → 変更確定 → 非エディット状態 + カーソル移動
  └─ Escape → 変更キャンセル → 非エディット状態
```

**タイプ編集（Type-to-Edit）:** 非エディット状態で印字可能文字を押すと、即座にエディット状態へ移行し、入力文字が初期値として入る（Excelと同じ挙動）。対象型は `string` / `integer` / `number` / `date` のみ。`enum` / `ref` / `boolean` / `json` / `text` は対象外。IMEオフ（1文字キー）のみ対応。

## 矩形選択（範囲選択）

Shift+矢印キー、またはマウスのドラッグで複数セルを矩形範囲で選択できる。

- **anchorCell（起点）:** 最初にクリックまたはカーソルを置いたセル。Shift 操作中は固定される。
- **cursor（フォーカスセル）:** 現在の移動先。矩形の対角を表す。
- 選択範囲は `SelectionBounds`（minRow/maxRow/minCol/maxCol）として計算し、範囲内セルを `bg-blue-100` でハイライト表示。
- 単純移動（Shift なし）では anchorCell とカーソルが同時にリセットされ、単一セル選択になる。

**今後の対応（未実装）:** 矩形選択への一括 Delete/クリア、コピー&ペースト。

## レスポンシブ対応方針

- **メインターゲット:** デスクトップ（1280px 以上）
- **タブレット（768px〜）:** 左サイドバーを折りたたみに変更
- **モバイル:** 対応しない（ゲームデータ編集ツールの性質上不要）
