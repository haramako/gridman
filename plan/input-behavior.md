# 入力挙動の比較と設計思想

## 概要

現在のコードベースにおけるキー/マウス入力に対する挙動と、Excelでの挙動を比較し、
GRIDMANのあるべき挙動を設計思想から予測した表。

---

## 主要な差異の詳細

### 1. Enterキー（最大の違い）
- **現在**: Enterで編集モード開始
- **Excel**: Enterで下のセルへ移動
- **予測**: WebスプレッドシートとしてのUXを優先した意図的な設計。編集確定後のEnterで次行へ移動する挙動は検討の余地あり

### 2. 列ヘッダークリック
- **現在**: 列ソート（昇順⇄降順トグル）
- **Excel**: 列全体を選択
- **予測**: Phase 1でボーナス機能として実装済みの意図的差異。ソート優先で現状維持が妥当

### 3. 未実装ショートカット
- Ctrl+X（カット）、Ctrl+A（全選択）、Page Up/Down、Ctrl+Arrow

## 優先度マトリックス

| 優先度 | 機能 | 理由 |
|--------|------|------|
| 高 | Enter確定後のセル移動 | 編集ワークフロー改善 |
| 高 | Ctrl+X（カット） | コピー/ペーストとの一貫性 |
| 中 | 行番号ドラッグ | 行削除UX改善 |
| 中 | Ctrl+A（全選択） | 基本ショートカット |
| 低 | Page Up/Down | 仮想スクロールで代替可 |
| 低 | オートフィル | コスト高・優先度低 |
