# MVP スコープ

## 基本方針

「Excelの代替としてゲームデータを編集できる最小限の環境」を最初のゴールとする。
高度なビュー機能（ルックアップ編集・ページビュー）は後続フェーズで追加する。

---

## フェーズ構成

```
Phase 1: コアエディター     ← MVP（完了）
Phase 2: ビューシステム
Phase 3: ルックアップ編集・ページビュー
Phase 4: Web対応・拡張
```

---

## Phase 1: コアエディター（MVP）✅ 完了

**ゴール:** 1つのプロジェクト（複数テーブル）をローカルで開き、スプレッドシート形式で編集・保存できる。

### プロジェクト管理
- [x] フォルダを指定してプロジェクトを開く
- [x] `project.json` + `*.jsonl` + `*.schema.json` の読み込み
- [x] 最近開いたプロジェクトの一覧表示

### テーブル表示・編集
- [x] 複数テーブルの切り替え（左サイドバー）
- [x] 仮想スクロール対応のスプレッドシートグリッド
- [x] セル編集（キーボード・マウス両対応）
- [x] 行の追加・削除
- [x] 列幅のリサイズ
- [x] テーブル内テキストフィルター

### カラム型と表示
- [x] `string` / `integer` / `number` / `boolean` / `enum` の基本型
- [x] 型に応じた編集ウィジェット（テキスト・数値・チェックボックス・セレクト）
- [x] `ref` 型: 参照先の `isDisplayName` 列を表示、セレクトで編集
- [x] `json` 型: テキスト省略表示のみ（編集は Phase 3）

### ソフトバリデーション
- [x] バリデーション違反でも入力を受け付ける
- [x] 変更済みセル: 黄色ハイライト
- [x] バリデーション違反セル: 赤枠 + ツールチップにエラー内容

### ファイル保存
- [x] 手動保存（Ctrl+S）
- [x] 変更行のみ差分保存（PATCH）
- [x] 未保存変更の表示（タイトルバーに `*` など）
- [x] `_invalid` を含む状態のまま保存（違反状態を永続化）

### バックエンド（Hono）
- [x] プロジェクトフォルダの読み書き API
- [x] ビルド済み SPA の配信

### Phase 1 の完了定義 ✅

1. `project.json` + `enemy.jsonl` + `enemy.schema.json` を含むフォルダを開ける
2. enemy テーブルをスプレッドシートで表示・編集できる
3. `ref` 型: 参照先の `isDisplayName` 列を表示、セレクトで編集できる
4. バリデーション違反の値を入力してもデータが消えず、赤枠で表示される
5. Ctrl+S で `enemy.jsonl` に保存され、再度開いたときに変更が反映されている

### Phase 1 で追加実装された機能（計画外）

- 複数セル範囲選択（Shift+矢印キー）
- 範囲コピー＆ペースト
- ヘッダークリックによる列ソート

## Phase 3: ルックアップ編集・ページビュー ⚠️ ほぼ完了

**ゴール:** 参照先データをビュー上で直接編集できる。1レコードをカード形式で閲覧・編集できる。

- [x] ルックアップビュー（参照先列の展開表示）
- [x] ルックアップビュー経由での編集（`_sources` マッピング + 共有参照の警告）
- [x] `json` 型カラムの専用エディター（サイドパネル）
- [x] ページ/カードビュー（JSON テンプレート定義）
- [x] Undo / Redo（Ctrl+Z/Y、単一セル・複数セル・行追加/削除の取り消し・やり直し）
