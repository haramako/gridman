# MVP スコープ

## 基本方針

「Excelの代替としてゲームデータを編集できる最小限の環境」を最初のゴールとする。
高度なビュー機能（ルックアップ編集・ページビュー）は後続フェーズで追加する。

---

## フェーズ構成

```
Phase 1: コアエディター     ← MVP
Phase 2: ビューシステム
Phase 3: ルックアップ編集・ページビュー
Phase 4: Web対応・拡張
```

---

## Phase 1: コアエディター（MVP）

**ゴール:** 1つのプロジェクト（複数テーブル）をローカルで開き、スプレッドシート形式で編集・保存できる。

### プロジェクト管理
- [ ] フォルダを指定してプロジェクトを開く
- [ ] `project.json` + `*.jsonl` + `*.schema.json` の読み込み
- [ ] 最近開いたプロジェクトの一覧表示

### テーブル表示・編集
- [ ] 複数テーブルの切り替え（左サイドバー）
- [ ] 仮想スクロール対応のスプレッドシートグリッド
- [ ] セル編集（キーボード・マウス両対応）
- [ ] 行の追加・削除
- [ ] 列幅のリサイズ
- [ ] テーブル内テキストフィルター

### カラム型と表示
- [ ] `string` / `integer` / `number` / `boolean` / `enum` の基本型
- [ ] 型に応じた編集ウィジェット（テキスト・数値・チェックボックス・セレクト）
- [ ] `ref` 型: 参照先の `isDisplayName` 列を表示、セレクトで編集
- [ ] `json` 型: テキスト省略表示のみ（編集は Phase 3）

### ソフトバリデーション
- [ ] バリデーション違反でも入力を受け付ける
- [ ] 変更済みセル: 黄色ハイライト
- [ ] バリデーション違反セル: 赤枠 + ツールチップにエラー内容

### ファイル保存
- [ ] 手動保存（Ctrl+S）
- [ ] 変更行のみ差分保存（PATCH）
- [ ] 未保存変更の表示（タイトルバーに `*` など）
- [ ] `_invalid` を含む状態のまま保存（違反状態を永続化）

### バックエンド（Hono）
- [ ] プロジェクトフォルダの読み書き API
- [ ] ビルド済み SPA の配信

### Phase 1 の完了定義

以下がすべて動作すること:

1. `project.json` + `enemy.jsonl` + `enemy.schema.json` を含むフォルダを開ける
2. enemy テーブルをスプレッドシートで表示・編集できる
3. `ref` 型: 参照先の `isDisplayName` 列を表示、セレクトで編集できる
4. バリデーション違反の値を入力してもデータが消えず、赤枠で表示される
5. Ctrl+S で `enemy.jsonl` に保存され、再度開いたときに変更が反映されている

---

## Phase 2: ビューシステム

**ゴール:** 保存可能なビューを定義・管理できる。

- [ ] フィルタービュー（GUI で条件定義・保存）
- [ ] ユニオンビュー（複数テーブルを縦結合）
- [ ] ビュー経由での編集（フィルター・ユニオン）
- [ ] テーブル横断検索
- [ ] `project.json` へのビュー定義の読み書き
- [ ] プロジェクト全体共有 enum 定義

---

## Phase 3: ルックアップ編集・ページビュー

**ゴール:** 参照先データをビュー上で直接編集できる。1レコードをカード形式で閲覧・編集できる。

- [ ] ルックアップビュー（参照先列の展開表示）
- [ ] ルックアップビュー経由での編集（`_sources` マッピング + 共有参照の警告）
- [ ] `json` 型カラムの専用エディター（サイドパネル）
- [ ] ページ/カードビュー（JSON テンプレート定義）
- [ ] Undo / Redo

---

## Phase 4: Web対応・拡張

**ゴール:** ローカルサーバーなしでも動作する環境と、運用上の利便性向上。

- [ ] File System Access API 対応（サーバーなし・Chrome/Edge）
- [ ] スキーマ編集 UI
- [ ] ファイルエクスポート（JSON / CSV）
- [ ] カラムのソート（ヘッダークリック）
- [ ] 列の表示/非表示切り替え
- [ ] DB バックエンドアダプター（将来の拡張口）
