# 入力挙動の比較と設計思想

## 概要

現在のコードベースにおけるキー/マウス入力に対する挙動と、Excel の挙動を比較した仕様表。
実装時の判断基準・意図的な差異の根拠として参照すること。

## 主要な差異の詳細

### 1. Enterキー（最大の違い）
- **現在（非編集モード）**: Enterで編集モード開始
- **現在（編集モード）**: 確定して下のセルへ移動
- **Excel**: どちらのモードでも下のセルへ移動
- **方針**: 非編集モードの Enter は編集開始のままとする。編集確定後の下移動は実装済みで Excel に準拠

### 2. 列ヘッダークリック
- **現在**: 列ソート（昇順⇄降順トグル）
- **Excel**: 列全体を選択
- **方針**: Phase 1でボーナス機能として実装済みの意図的差異。ソート優先で現状維持

### 3. 未実装機能
- フィルハンドル（オートフィル）：コスト高・優先度低
