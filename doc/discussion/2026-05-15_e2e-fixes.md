# E2E テスト自動起動・テスト失敗の修正

**日付**: 2026-05-15  
**関連ファイル**: `playwright.config.ts`, `src/components/spreadsheet/SpreadsheetGrid.tsx`, `e2e/page-view.spec.ts`, `biome.json`

## 相談内容

2つの独立した E2E 問題を修正した。

**問題1**: `npm run test:e2e` でサーバーが自動起動しない。`playwright.config.ts` の `webServer` に `reuseExistingServer: true` があるが、サーバーが停止していると Playwright が 60 秒でタイムアウトする。

**問題2**: E2E テスト 16 件が失敗している（Enter/F2 でセルが編集モードに入らない、Ctrl+↑↓←→ が動かない など）。

## 検討した選択肢

**問題1**（サーバー自動起動）:
- `npm run server`（= `tsx watch server/index.ts`）を維持: `tsx watch` は TTY なしのサブプロセスとして起動するとサイレントに停止するため不可
- `npx tsx server/index.ts`（watch なし）に変更: 採用。サブプロセスとして確実に動作する

## 決定事項

### サーバー自動起動

1. **`playwright.config.ts` の `command` を `npx tsx server/index.ts` に変更** — `tsx watch` の TTY 依存を回避。E2E 実行時はファイル監視不要なので watch なしで問題なし
2. **テストタイムアウトを 30s → 60s に延長** — Vite コールドスタート中に 30 秒制限が切れるケースを防ぐ

### テスト失敗（リグレッション修正）

3. **`tabIndex={0}` を `SpreadsheetGrid.tsx` に復元** — `9cc710b` の「機械的リファクタリング」コミットが Biome の `noNoninteractiveTabindex` 警告を "fix" として削除していた。`tabIndex` はグリッドコンテナのキーボードフォーカスに必須。`biome.json` の override で再発防止
4. **`page-view.spec.ts` のセレクタを `getByRole('dialog')` に変更** — `1e7360f` の「セマンティックHTML化」コミットで `<div role="dialog">` → ネイティブ `<dialog>` 要素に変更されたが、テストの `[role="dialog"]` CSS セレクタは ARIA ロールを参照しないため不一致

### AI タスクに起因するリグレッション防止

5. **biome.json に `overrides` を追加** — `SpreadsheetGrid.tsx` の `noNoninteractiveTabindex` / `useSemanticElements` を無効化し、同じ AI "fix" が再発しないよう保護
6. **根本パターンの識別**: lint 修正・リファクタリング系 AI タスクが E2E テストを実行せずにマージされるとこのパターンが再発する

## 変更されたファイル

- `playwright.config.ts` — `npm run server` → `npx tsx server/index.ts`、`timeout: 60000` 追加
- `src/components/spreadsheet/SpreadsheetGrid.tsx` — `tabIndex={0}` + `role="grid"` 復元
- `e2e/page-view.spec.ts` — `[role="dialog"]` → `getByRole('dialog')`
- `biome.json` — `overrides` で SpreadsheetGrid.tsx の a11y ルール 2 件を除外

## 未解決・持ち越し

- AI タスク（lint 修正・リファクタリング系）に「E2E テスト実行を必須とする」条件を AGENTS.md に追記することを検討
- `[role="..."]` CSS セレクタを使っている E2E テストが他にないか定期確認（今回は 1 件のみだった）
