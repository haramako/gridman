# Input Behavior

キーボード・マウス入力の仕様。Excel を基準とした比較表と、意図的な差異の解説。

## キーボード操作

| 操作 | 挙動 | Excel との差異 |
|------|------|--------------|
| `↑↓←→` | カーソル移動 | なし |
| `Shift+↑↓←→` | 範囲選択（矩形） | なし |
| `Ctrl+↑↓` / `Ctrl+←→` | データ端へジャンプ | なし |
| `Ctrl+Shift+↑↓←→` | データ端まで範囲選択 | なし |
| `Home` / `End` | 行の先頭/末尾列 | End はやや異なる |
| `Page Up` / `Page Down` | 1 画面スクロール | なし |
| `Tab` / `Shift+Tab` | 右/左セルへ移動 | なし |
| **`Enter`（非編集モード）** | **編集モード開始** | **Excel は下セルへ移動（意図的差異）** |
| `Enter`（編集モード） | 確定して下のセルへ | なし |
| `F2` | 編集モード開始 | なし |
| `Escape` | 編集キャンセル | なし |
| `Delete` / `Backspace` | セル値クリア | なし |
| `Ctrl+C` | TSV コピー | なし |
| `Ctrl+V` | TSV ペースト（複数セル対応） | なし |
| `Ctrl+X` | カット（コピー＋クリア） | なし |
| `Ctrl+A` | 全選択 | なし |
| `Ctrl+Z` / `Ctrl+Y` | Undo / Redo | なし |
| `Ctrl+S` | 保存 | なし |
| `Ctrl+Shift+F` | 検索ページへ移動 | 独自機能 |
| 印字可能文字 | type-to-edit（即編集開始） | なし |

### Enter キーの意図的差異

非編集モードの Enter が **編集開始** なのは意図的設計。ゲームデータ編集ではセルの確認より編集頻度が高く、1 キーで編集に入れる方が効率的との判断。

### Ctrl+V のグローバルリスナー

`navigator.clipboard.readText()` は HTTPS 必須のため、`document` の `paste` イベントを使うグローバルリスナーで実装。`clipboardData.getData('text/plain')` で TSV テキストを取得する。

## マウス操作

| 操作 | 挙動 | Excel との差異 |
|------|------|--------------|
| クリック | カーソル移動 | なし |
| ダブルクリック | 編集モード開始 | なし |
| ドラッグ | 矩形範囲選択 | なし |
| **列ヘッダークリック** | **列ソート** | **Excel は列全体選択（意図的差異）** |
| 列ヘッダーのドラッグ端 | 列幅リサイズ | なし |
| 行番号クリック | 行選択 | なし |
| 右クリック | コンテキストメニュー | なし |

## 読み取りモード

`writeMode = false`（他タブがロックを保持）の場合:
- セル選択・ナビゲーション・コピーは可能
- 編集・行追加/削除は不可
- 列ソート・フィルターは可能（Excel 保護とは異なる）
